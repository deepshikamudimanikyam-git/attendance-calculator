# attendance-calculator
A C program that calculates student attendance percentage and checks exam eligibility

## Features
- Takes total number of lectures as input
- Takes number of lectures attended
- Calculates attendance percentage
- Displays whether the student is eligible for exams

## Technologies Used
- C Programming Language
- GCC Compiler

## How to Run
1. Compile the program:
   ```bash
   gcc rtp1.c -o attendance
# sample input 
Enter total number of lectures: 100
Enter number of lectures attended: 45
# sample output
Your attendance percentage is: 45%
You are not eligible for writing exams
